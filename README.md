# 🎬 Movie Recommendation System

## 📌 Project Description

This project is a **Movie Recommendation System** built using **Machine Learning** that suggests movies based on user preferences.
It uses a **content-based filtering technique** to recommend similar movies.

The project also includes a **Streamlit-based frontend** for an interactive user experience.

---

## 🚀 Features

* 🎯 Recommend similar movies instantly
* 🧠 Uses content-based filtering algorithm
* 📊 Cosine similarity for accurate recommendations
* 🌐 Interactive UI built with **Streamlit**
* ⚡ Fast and user-friendly interface

---

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn

## ▶️ How to Run the Project

### 1️⃣ Clone Repository

```bash
git clone https://github.com/mnsankhat/movie-recommendation-system.git
cd movie-recommendation-system
```

### 2️⃣ Install Requirements

```bash
pip install -r requirements.txt
```

### 3️⃣ Run Streamlit App

```bash
streamlit run app.py
```

---

## ⚙️ How It Works

1. Movie dataset is processed using Pandas
2. Important features are extracted
3. Text data is converted into vectors
4. Cosine similarity is calculated
5. Top similar movies are recommended
